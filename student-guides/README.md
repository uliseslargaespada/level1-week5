# Week 5 student guides

This week has classes on **Monday, November 23; Tuesday, November 24; and Wednesday, November 25, 2026**, from **6:30 to 9:30 p.m. CST**. Thursday and Friday are off. You may use the remaining days for practice and finishing your work; there are no extra holiday lessons to complete.

You will submit **two Moodle assignments, worth 5 points each**, by **Sunday, November 29, at 10:59 p.m. CST (America/Tegucigalpa)**. Both submissions contain the **same public GitHub repository URL**. Your daily work and mini-project occupy different folders in that repository.

## Work through these guides in order

1. [Git and GitHub: from a folder to your first push](01-git-and-github.md). Use this for Monday's setup and the save, test, stage, commit, push routine.
2. [Opening webpages and using DevTools](02-browser-and-devtools.md). Use this for Tuesday's HTML/CSS and Wednesday's browser JavaScript.
3. [Study guide with worked examples and answers](03-study-guide.md). Use this to revisit the concepts and practise tracing a short interaction.
4. [Repository organization and final submission](04-repository-submission.md). Use this for both Moodle entries.

The [editable study presentation](../presentation/week-5-git-and-interactive-pages.pptx) includes worked examples, prediction questions, and answers.

Open [Assignment 1: daily exercises](../assignments/daily-exercises/README.md) and [Assignment 2: mini-project](../assignments/mini-project/README.md) before starting. They describe the exact work and grading. The study examples explain a related problem; you still write your own submission.

## Use the correct copy of your work

The full student pack contains this reading material, the assignment instructions, and a starter folder. The separate starter ZIP contains only the starting files for your own repository. Use [the first guide](01-git-and-github.md#2-create-your-own-work-folder) to choose one setup route.

Your work folder should show `README.md`, `daily-exercises/`, and `mini-project/` directly at its top level. Edit the files in this folder. A change inside a different download or old Week 4 folder will not appear when you push the Week 5 repository.

If you leave breakout briefly for a Badge 2 interview, save your work and write your next step in your task notes. Resume that same step afterward. Badge 2 is separate from the two Week 5 assignments.

## Before asking a TA for help

Tell them which file you opened, what you expected, what happened, and the smallest check you tried. Paste an error message as text when appropriate. Use fictional content in all public files. Keep passwords, authentication codes, tokens, personal contact details, and student records out of the repository.
