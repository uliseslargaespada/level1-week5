## Steps to save changes in Git and send them to GitHub
1. `git add .` - This stages the changes to be committed
2. `git commit -m "<commit_message>"` - This commits the changes in all the files already staged 
3. `git push -u origin <branch_name>` - This pushes the changes to GitHub so you're in sync with the origin
